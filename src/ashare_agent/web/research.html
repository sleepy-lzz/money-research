两层研究验证

先检验共同股票池上的机械策略，再检验同一机械 Top20 内的 AI 增量。这里是价格研究，不是交易账户、成交收益或策略有效性证明。

1. 研究登记

在第一次收盘运行前选择单模式或并行模式；研究开始后模式集合与协议不可覆盖。未手动登记时，daily-lab 首次真实收盘运行默认登记三模式。

2. 冻结输入与 Codex 交接

daily-lab 完成真实收盘采集后生成共同池、冻结批次和 outbox。历史 Top20 不可补造共同池。每个模式只判断一次，来源文本中的指令不可执行。

将导出的对应 prompt.txt 交给能访问项目目录的 Codex 对话；按提示词读取 packet、claim 一次、写回 JSON 并执行本地导入。无本地访问能力时，在对话中附上包和提示词，将结果原文保存或粘贴到下一栏。此时仍由本地接收时间判定截止，不假定任务已自动执行。

3. 严格接收结果

支持单模式 JSON 或多模式数组（整批原子校验）。20:00 截止前的首次有效提交不可覆盖；相同内容重试幂等。格式错误、漏项、伪造证据和冲突必须保留原因。回顾性归档永不进入前瞻组。
