# 网页工作台与当前研究

双击根目录“启动工作台.cmd”。首次可点“真实数据检查”。交易日 16:00 后点击“一键真实选股”：股票范围留空检查新浪返回的主板目录，首次可能需要数十分钟；也可输入少量代码试用。候选表支持搜索、点击列标题排序、CSV 导出和打开报告，侧栏可查看历史任务。运行中可以取消，关闭浏览器不会停止后台任务。

默认过滤最近 251 个基准交易日资料完整且有成交、20 日平均成交额至少 1 亿元、前复权价格高于 MA120、60/120 日动量同时为正，按动量排名取 20 只。输入成交额单位是万元。当前研究不生成订单，不提供个人持仓建议。

## 架构

网页 → 固定操作 API → 独立 Python 子进程 → CurrentClient → 当前筛选 → JSON / CSV / HTML 报告。

- `webapp.py`：本地 HTTP 服务、参数与 CSRF 校验、单任务、取消和历史记录。仅绑定 127.0.0.1，不接受任意 shell 或文件路径。
- `web/index.html`：无外部 CDN 的中文响应式网页，候选表、日志、错误与报告。
- `current_data.py`：客户端级直连/环境代理、限速重试、不可变原始响应、下载时间和 SHA-256。新浪证券目录与最新报价，腾讯原始/前复权日线。
- `current_screen.py`：固定基准日期、双源当日量价与名称核验、过滤排名、报告。
- 原 Snapshot / Engine / SQLite ledger：继续执行严格历史回测门禁。当前研究不调用账本及订单链路。

原始价格用于显示与当日交叉核验，前复权仅用于当前时点的历史趋势。腾讯主板成交量由手乘 100 转股，成交额由万元乘 10000 转元，不能拿收盘价乘量代替真实成交额。

## 数据状态和边界

目录逐页核验数量、排序、唯一代码和首尾总数，只证明新浪本次返回目录内部一致，不是交易所全市场目录独立证明，更不能消除历史退市幸存者偏差。

运行要求上海时间 16:00 后、基准最新日期为今天、报价已收盘且不晚于截止时间。固定最近 251 个基准观测日期，不能取交集掩盖个股缺口。个股缺失或双源不一致使结果为 partial；核心基准或目录失败为 blocked。休市日暂不生成新的今日名单，可查看已保存报告。

`fetched_at / available_at` 是实际获取时间，不是虚构的历史可见时间。保存请求参数、网络模式、版本、响应和哈希，只证明采集记录一致性，不能证明第三方历史版本绝对正确。缓存仅复用当天 16:00 后且半小时内响应。今天获取的旧行情不获准进入严格历史 PIT 模拟。

ST/退市过滤依据双源当前名称，不能保证覆盖所有未体现在名称上的风险状态。当前选股页未启用历史行业限制或 AI 决策。独立的[持续计划页](CONTINUOUS_PLANS.md)已增加前瞻新闻/社区采集、手工持仓和条件计划；这些材料不进入严格历史回放，不能由 LLM 自报可见时间。

结果位于 `runtime/web-runs/<id>/`；原始响应与采集元数据位于 `runtime/current-cache/<request-hash>/<revision>/`。报告附参数、代码指纹、排除原因；筛选后的序列保存为 Parquet。

“已完成”仅指请求范围检查完成；“部分完成”候选只代表成功检查的子集；“数据未就绪”不能当作成功选股。合成演示收益不能评价策略。旧高级历史命令仍在 CLI，本轮未迁移所有历史管理控件到网页。

```powershell
.venv\Scripts\python.exe -m ashare_agent.webapp
.venv\Scripts\python.exe -m ashare_agent current-doctor --output runtime/my-doctor
.venv\Scripts\python.exe -m ashare_agent current-screen --symbols 000001.SZ,600000.SH --output runtime/my-current-screen
```
