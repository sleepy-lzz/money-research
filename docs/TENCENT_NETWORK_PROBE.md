# 腾讯行情与代理对照测试

2026-09-10，本机 Python/httpx 小样测试。没有安装完整 AKShare；根据其官方
`stock_hist_tx.py` 中的请求格式，直接测试腾讯上游 HTTPS 接口。
没有改动系统代理、Codex 配置、生产下载器或交易规则。

## 结果

当前进程存在 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY，均指向本地代理。
同一腾讯日线请求沿用代理时出现 WinError 10054，`trust_env=False` 直连成功。

| 样本 | 网络模式 | 结果 |
| --- | --- | --- |
| sh600000 不复权 | 沿用配置 | 连接重置，无行情 |
| sh600000 不复权 | 本次请求直连 | 641 行，最新 2026-09-10 |
| sz000001 不复权 | 本次请求直连 | 641 行，最新 2026-09-10 |
| sh600519 不复权 | 本次请求直连 | 641 行，最新 2026-09-10 |
| sh600000 前复权 | 本次请求直连 | 640 行，最新 2026-09-10 |

以上返回 provider code 0；各成功序列无重复日期，严格递增，OHLC 大小关系检查通过。
这支持行情采集使用独立网络策略，不需要关闭用户用于 Codex 的全局代理。
但这是有限样本，未证明供应方服务长期稳定或数据本身全部正确。

## 额外发现

* 服务返回区间早于请求开始日期，且行数接近上限。适配器必须显式裁剪、分页和检查覆盖，
  不能把 HTTP 200 等同于请求日期完整。
* 对不复权样本，在假设原成交额以万元计的前提下，成交量按“手 ×100”归一后，
  三只股票每行的成交均价均落在当日高低价范围附近；按“股”解读则不符合。
  此为量纲一致性测试，尚未与独立行情源核对。
* 本次读到的 AKShare main 源码将 `sz000` 与部分指数前缀一起排除于 volume ×100 之外。
  实测 sz000001 需要按手换算，接入前必须复核，不能直接照搬该分支规则。
* 前复权与原始序列行数不同；不能按行号对齐，应以代码/日期合并。
* 尚未测试全市场主板集合、ST/停牌、行业、退市覆盖；不能据这些日线样本发布完整选股名单。
