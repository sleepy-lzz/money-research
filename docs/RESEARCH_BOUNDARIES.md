# 研究边界

当前项目的“选股”是一个可复现的机械研究基线：主板资格、连续行情、成交额、MA120 和 60/120 日动量。它用于建立固定对照，不代表已经证明适合所有 A 股阶段。下一批实验可以登记反转、行业暴露和市场状态，但必须使用同一时间切分、成本、成交规则和未知处理，并在样本不足时保留所有组，不自动选择最优组。

daily-lab 的 D+1/D+5/D+20 是冻结候选后的价格观察，不是券商成交、现金账户收益、净值或 Alpha 证明。Paper 账本是独立模拟工作区，可信前瞻 Snapshot、成交拒绝、费用、T+1 和公司行为闭环未验收前不能当作实盘替代。

当前实时 screen 目录和日线接口不等于历史某天完整、可见且含退市股票的 PIT 全市场股票池。严格历史回测继续 fail closed；没有证据就不补造历史 universe。

AI overlay 先做人工/半自动 Codex JSON 研究输入。机械基线、保守、平衡、激进四组只有在 overlay 接入同一前瞻观察汇总后才可以做实际对照；在此之前只表示“已建立安全导入接口”，不能表示 AI 已经验证有效。
