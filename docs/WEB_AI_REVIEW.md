# 网页 AI 复核中心

启动工作台后，左侧点击 **AI 复核中心**，或访问 `/ai-review`。如已运行旧版本，需要重新启动工作台后刷新网页。

1. 选择冻结日期，点击 **下载分析包** 和 **复制复核提示**，把文件和提示交给固定的“每日 AI 复核”对话。
2. 对话返回三种模式的 JSON 后，在网页选择文件（可多选），或直接粘贴 JSON 数组。
3. **只校验**不保存；**校验并导入**会在全部通过后原子写入。失败会显示具体原因。重复相同结果不新增记录，不同结果不覆盖已有模式。
4. 判断差异表可展开查看理由与引用 ID；价格观察表显示机械基线及按时提交的 AI 三种模式的 D+1/5/20 已知、未知、等待数量、均价涨幅和指数差值。后续 daily-lab 收盘运行会采集这些观察组需要的股票数据。

网页导入使用 `review_imports` 表，与旧版只存结果的 `overlay_results` 分开。旧数据不会被静默提升为前瞻样本；请通过网页重新校验原始 JSON，晚到仍标为事后复核。

## 固定的比较规则

- 每种模式从同批 Top20 出发；保持机械评分降序及代码平局排序，把 `deprioritize` 稳定移到末尾，取前5。`keep` 和 `unknown` 不改变顺序；省略的股票也按 unknown 回退。
- 三种模式是三份独立 AI 判断，当前计算方法相同，没有三套不同仓位/成本规则。
- 服务端记录实际接收时间。只有冻结当日上海时间20:00之前收到的结果进入前瞻观察；其他结果仍可查看判断，但不能回填历史观察组。这个截止规则为本版固定实验约定，不代表交易所规则。
- 股票、输入哈希、同股证据、证据时间链、额外字段和重复冲突均由服务端检查。AI 自报的生成时间不是服务端接收时间。
- 价格观察复用现有 ForwardLab 的原始价/复权一致性和交易日检查。没有模拟成交、净收益或收益保证；不改变真实账户或交易计划。均值忽略未知样本而保留未知计数，不应作为全策略收益。
- 当前接入层能约束可引用材料与提交时点，不能证明模型内部绝无其他知识或用户没有手改文件，因此不能称为“绝对无未来信息”的历史回测。

技术验证包括 HTTP 来源/CSRF、网页加载与错误提示、原子导入、重复冲突、同股证据绑定、迟到隔离和 D+1/5/20 观察。真实 AI 前瞻效果必须等待实际按时提交的样本，不能用测试数据代替。
