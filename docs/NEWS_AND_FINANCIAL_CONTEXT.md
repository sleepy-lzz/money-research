# 国内外事件与财报参考

在“持续交易计划”收盘复核后，最新计划会显示“国内外事件参考”和“财报参考”。重新双击启动工作台，再于交易日 16:00 后复核即可获取。此前的旧计划不会补贴新材料；升级后规则版本改变，需要重新复核。此功能不需要 Tushare 财务权限。

## 当前已实现

- 国内货币/财政政策、经济与产业、海外利率汇率、国际贸易技术限制、能源地缘五类主题，使用东方财富聚合检索；另读取美联储官方货币政策 RSS。近 7 日，每个主题来源最多展示 5 条，属于有限检索样本。
- 每条材料显示来源级别、发布时间、真实获取/可见时间，以及正反两种影响情景。情景不代表已经发生或已确认利好利空；没有公司收入/成本/供应链暴露证据时，不自动对应具体持仓。官方 RSS 是公告摘要，聚合报道也不冒充已核验的官方原文。
- 所有候选及持仓（合计最多 50 只）逐股读取东方财富按报告期财务摘要，每股读取最多 8 行、展示最多 4 期。展示营业总收入、归母和扣非净利润、每股经营现金流、加权 ROE、资产负债率及营收/归母同比；单位明确，缺失保留未知。
- 财务摘要尚不包括完整三大报表原文、审计意见、预约披露日历、公告逐项核验或行业内估值比较。累计利润/现金流不标作单季度或 TTM；不将每股现金流混称现金流总额，不将同比增长称为超预期。

这两层目前均为**参考用途，交易权重为 0**，不改变机械排名、股数、止盈止损或市场开关。原来的 70/20/10/0 仍只是未校准的综合展示预设，不能解释为真实交易贡献。财报、宏观也不额外塞入该分数，避免重复计分。

## 可信度与时间

- 新闻缺少明确小时/分钟、晚于实际获取或决策截止、主题不匹配时拒绝；海外 RSS 必须有时区，转换成北京时间。RSS 无近期材料与请求失败分别显示，不把它们当成“没有风险”。
- 财报的 `NOTICE_DATE/UPDATE_DATE` 只有日精度，保存为来源公告日/修订日，`published_at=null`。本工具知道该版本的时间来自真实请求回执，不能由公告日推断其零点已可见。
- 同一期财报内容/口径冲突、未来日期、股票错配、币种不支持或指标无效时，该代码标为未核验，不静默退回较老报告冒充最新。
- 原始响应、SHA256、请求和获取时间保存在 `runtime/current-cache`；派生材料分别作为 `market_context/financial_context` 冻结进计划 SQLite 和运行 JSON，纳入输入哈希。后续更正形成新的采集版本，不重写过去计划。
- 不将今天下载的旧数据用于过去决策，不接入严格历史回测。没有数据完整性/事实真实性或策略有效性的保证。

当前随收盘计划复核采集，不是盘中实时新闻推送。盘中报价仍由独立监控模块更新。来源失败只在对应参考区显示缺口，不会把已有行情计划变成新闻自动交易策略。

## 独立研究与取舍

`gpt-6-astra / xhigh` 已查阅公开研究、维护方文档和 GitHub 实践，报告见 [因子研究](FACTOR_RESEARCH_2026-09-11.md)。主代理接受：财报事实优先、宏观条件情景、社区零交易权重，以及分别对照的研究方法。

报告提出的机械/财务 90/10、机械/新闻 95/5 仅登记为待验证实验，**本版不实施这些权重**。财务 90/10 的定义依赖可信 TTM、行业历史口径和足够横截面覆盖，当前摘要不能满足；事件窗口过滤依赖当时已知的预约披露日历，当前也不满足。先补原始披露核验及数据质量，再考虑启动单变量对照。不会每天搜索一个收益更好的比例。
